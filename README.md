# Human Activity Recognition

Akilli telefon sensorleri ivmeolcer ve jiroskop verileri kullanilarak gunluk insan aktivitelerinin siniflandirilmasi amaciyla hazirlanmis bir calismadir. UCI HAR veri seti uzerinde cesitli makine ogrenmesi algoritmalarinin basarimlari karsilastirilmis olup ayrica model egitimi icin train.py ve test_kontrol.py uzerinden calisan testler eklenmistir. Projede farkli modellerin sonuclari ve karsilastirmalari yer almaktadir, calistirmak icin requirements.txt dosyasindaki paketler kurulup ilgili scriptler ya da notebook dosyasi calistirilabilir.
